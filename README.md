# SamirNet Player

مشغّل وسائط محلي لنظام Android باستخدام Flutter وDart، بواجهة عربية RTL وهوية لونية مرجانية. هذا المستودع يبدأ من الصفر، وتُنفّذ الميزات تدريجيًا مع توثيق ما هو متاح وما لم يكتمل بعد.

## الموجود في النسخة الأولية

- واجهة عربية وتنقل: الرئيسية، المجلدات، المفضلة، السجل، الإعدادات.
- فهرسة فيديوهات الهاتف عبر `photo_manager` بعد طلب الإذن.
- صور مصغرة مستخرجة من الوسائط الحقيقية.
- البحث والتصفية الأساسية وعرض الشبكة أو القائمة.
- حفظ المفضلة وسجل العناصر التي شُغّلت محليًا.
- مشغل فيديو أساسي عبر `video_player` مع تشغيل/إيقاف، تقديم/ترجيع 10 ثوانٍ، شريط زمني وسرعات.
- حفظ إعداد المظهر الفاتح/الداكن/التلقائي.

## غير مكتمل بعد

الخزنة المشفرة، نقل Wi-Fi، تشغيل الصوت في الخلفية مع إشعارات الوسائط، إدارة الملفات المتقدمة، اختيار الترجمة الخارجية ومزامنتها، التحكم بالسطوع والإيماءات المتقدمة، والاختبارات على أجهزة حقيقية. لا تعتبر هذه الميزات مكتملة لمجرد ظهور عناصر توضيحية لها.

## المكتبات الأساسية

- Flutter / Dart
- `photo_manager` لفهرسة الوسائط والصور المصغرة.
- `video_player` لتشغيل الفيديو.
- `shared_preferences` لتفضيلات المستخدم وسجل بسيط.

## بناء APK عبر GitHub Actions

يُشغّل `.github/workflows/android.yml` عند الدفع إلى `main`. ينشئ سير العمل ملفات منصة Android الناقصة، ثم ينفذ `flutter pub get` و`flutter analyze` و`flutter test` و`flutter build apk --release`. بعد انتهاء التشغيل، افتح تبويب **Actions** ونزّل artifact باسم `samirnet-player-apk` إذا نجح البناء.

## البناء محليًا

يتطلب Flutter وAndroid SDK:

```bash
flutter create --platforms=android --org com.samirnet .
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

المسار المتوقع للملف: `build/app/outputs/flutter-apk/app-release.apk`.

## الأذونات والاختبارات

تُدار أذونات قراءة الوسائط من خلال `photo_manager`، ويجب اختبارها على إصدارات Android المختلفة. لا يحتاج تشغيل الوسائط المحلية إلى حساب أو مفتاح API. نجاح البناء الآلي لا يغني عن الاختبار اليدوي على هاتف حقيقي.

الإصدار الحالي: `0.1.0` (نسخة أولية).
