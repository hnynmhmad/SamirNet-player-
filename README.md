# SamirNet Player

مشغّل وسائط محلي لنظام Android باستخدام Flutter وDart، بواجهة عربية RTL وهوية لونية مرجانية. تُنفّذ الميزات على مراحل، مع الفصل بين الوظائف التي تمت إضافتها وما يحتاج اختبارًا على أجهزة حقيقية.

## الوظائف الموجودة في المشروع حاليًا

- واجهة عربية RTL مع الرئيسية والمجلدات والمفضلة والسجل والإعدادات.
- فهرسة فيديوهات الهاتف عبر `photo_manager` وصور مصغرة حقيقية.
- بحث وتصفية بحسب مدة الفيديو وعرض شبكة أو قائمة متجاوبة.
- حفظ المفضلة وسجل التشغيل محليًا.
- مشغل فيديو عبر `video_player` مع تشغيل/إيقاف، تقديم/ترجيع 10 ثوانٍ، سرعات، تدوير الشاشة، احتواء/ملء الشاشة، قفل عناصر التحكم، إخفاء تلقائي لعناصر التحكم، واستكمال من آخر موضع محفوظ.
- مظهر فاتح/داكن/حسب النظام.
- **الخزنة الخاصة:** تشفير الملفات المستوردة بـ AES-CBC مع مفتاح مشتق من الرقم السري، ووسم HMAC-SHA256 لاكتشاف التلاعب، وتخزين التحقق من الرقم السري عبر التخزين الآمن في Android.
- **استقبال عبر Wi-Fi:** خادم HTTP محلي مؤقت على شبكة الهاتف، ورمز Bearer عشوائي، وحفظ الملفات في مساحة التطبيق الخاصة، وبصمة SHA-256 محسوبة أثناء الاستقبال دون الاحتفاظ بالملف كاملًا في الذاكرة.

## حدود مهمة يجب معرفتها

- الخزنة لا تُشفّر تلقائيًا الفيديو الأصلي؛ يجب استيراده يدويًا. إذا نسيت الرقم السري فلا توجد آلية لاستعادة الملفات. احتفظ بنسخة احتياطية من ملفاتك قبل استخدامها.
- استقبال Wi-Fi موجّه للمطورين/الأجهزة التي تستطيع إرسال طلب HTTP مع رمز المصادقة؛ واجهة إرسال جاهزة برمز QR من جهاز إلى آخر ليست مضافة بعد. أوقف الخادم فور الانتهاء ولا تشارك رمز المصادقة.
- استعادة ملف من الخزنة تحفظه حاليًا باسم عام؛ اسم الملف الأصلي وامتداده لا يُحفظان في بيانات وصفية بعد.
- تشغيل الصوت في الخلفية مع إشعار تحكم، الترجمة الخارجية ومزامنتها، والتحكم الحقيقي بالسطوع والصوت عبر الإيماءات، واختبارات الأجهزة الفعلية ما زالت تحتاج مراحل إضافية. لا تُعدّ هذه الميزات منجزة بعد.
- يلزم نجاح GitHub Actions ثم اختبار APK على جهاز Android فعلي قبل وصف النسخة بأنها مستقرة.

## المكتبات

- `photo_manager`: فهرسة الوسائط والصور المصغرة.
- `video_player`: تشغيل الفيديو.
- `shared_preferences`: التفضيلات والمفضلة والسجل وموضع الاستكمال.
- `encrypt` و`crypto`: التشفير والتحقق من سلامة الملفات وبصمات النقل.
- `flutter_secure_storage`: حفظ تحقق الرقم السري في التخزين الآمن.
- `file_picker`: اختيار الملفات للاستيراد والاستعادة.
- `path_provider`: مساحة التطبيق الخاصة.

## بناء APK عبر GitHub Actions

يُشغّل `.github/workflows/android.yml` عند الدفع إلى `main`. ينشئ سير العمل ملفات Android ثم ينفذ `flutter pub get` و`flutter analyze` و`flutter test` و`flutter build apk --release`. بعد نجاح التشغيل، افتح تبويب **Actions** ونزّل artifact باسم `samirnet-player-apk`.

- [المستودع](https://github.com/hnynmhmad/SamirNet-player-)
- [حالة البناء والاختبارات](https://github.com/hnynmhmad/SamirNet-player-/actions)

## البناء محليًا

يتطلب Flutter وAndroid SDK:

```bash
flutter create --platforms=android --org com.samirnet .
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

مسار APK المتوقع: `build/app/outputs/flutter-apk/app-release.apk`.

الإصدار الحالي: `0.1.0` (قيد التطوير).
